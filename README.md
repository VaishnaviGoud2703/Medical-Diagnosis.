# Medical-Diagnosis.
AI-powered chest x-ray analysis using python and deep learning
AI-Powered Medical Imaging Assistant

Overview

An educational AI project that analyzes chest X-ray images using a pretrained deep learning model.

Features

* Upload chest X-ray images
* Analyze supported chest X-ray findings
* Display model prediction scores
* Generate a downloadable draft report
* Simple web interface built with Streamlit

Technologies Used

* Python
* PyTorch
* TorchXRayVision
* NumPy
* Streamlit
* scikit-image
* Pillow

Installation

Install the dependencies:

pip install -r requirements.txt

Run the Application

streamlit run app.py

Future Improvements

Disclaimer
